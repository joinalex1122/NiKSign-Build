Bản web sửa JSON và XML plist. Binary plist và gói mã hóa 3105PATCH cần bản native. Các tệp .3105 dạng JSON của bản NiKSign cũ được xuất lại thành .json, không coi là gói tương thích 3105.

Ký IPA cần app native đã cài, binary hợp lệ, chứng chỉ .p12 và provisioning profile. Bản web không ký, cài IPA hoặc truy cập container app khác.
